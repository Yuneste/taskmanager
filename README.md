# Personal Task Manager

A simple task management web application built with Java, Spring Boot, Thymeleaf, Spring Data JPA, and H2.

## Features

- Create tasks
- View all tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status
- Validate task input
- Store tasks in an H2 database
- Basic service and controller tests

## Tech Stack

- Java 17
- Spring Boot
- Maven
- Thymeleaf
- Spring MVC
- Spring Data JPA
- H2 Database
- JUnit 5
- Mockito
- Git

./mvnw spring-boot:run
